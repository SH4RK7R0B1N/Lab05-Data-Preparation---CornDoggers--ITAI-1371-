# Module 05 Lab: Data Preparation

## Description
This project focuses on preparing and cleaning data for machine learning using Python. In this lab, our group worked with the Titanic dataset and practiced important data preparation techniques such as handling missing values, one-hot encoding categorical data, and feature scaling.

## Tasks Completed
- Filled missing values in the Age column using the median.
- Used One-Hot Encoding for the Sex and Embarked columns.
- Used StandardScaler to scale the Age and Fare columns.
- Completed knowledge check questions about data preparation and machine learning.

## Tools and Technologies
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook / Google Colab

## Purpose
The purpose of this lab was to understand how raw data can be cleaned and transformed before being used in a machine learning model. This project helped us practice common data preprocessing techniques and understand why data preparation is an important part of machine learning.
